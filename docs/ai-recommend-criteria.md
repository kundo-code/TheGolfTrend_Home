# AI 골프여행 추천 — 판단 기준표

관리자 패널 › 상품 › 고급편집 › **🤖 AI 추천 정보**와 **숙소·골프장 등록부**의 입력 기준, 그리고 추천이 이 값을 어떻게 쓰는지 정리한 문서입니다.
화면의 각 항목 옆 ⓘ에도 같은 기준이 표시됩니다. (이 문서의 표는 화면과 같은 정의에서 만들었습니다.)

## 1. 판정 원칙
- **확인된 정보만 사용** — 관리자 입력값 → 기존 상품 등록값(숙소 위치·최소 인원·식사·라운드·이동시간·등급 등) → 상품 문구(태그·제목·대표 문구) 순으로 확인합니다.
- **미확인은 감점하지 않음** — 어디에도 정보가 없으면 '미확인'으로 두고 일부 점수만 줍니다(확인된 부합 > 미확인 > 확인된 불일치). 고객에게는 "상담 시 확인"으로 안내됩니다.
- **여러 숙소·골프장** — 상품에 연결된 숙소·골프장 중 **하나라도** 조건에 맞으면 부합입니다. 근거에 맞는 곳의 이름을 함께 보여 줍니다.
  값이 있는 곳이 모두 맞지 않고 나머지가 미등록이면 '미확인', 값이 있는 곳 모두 맞지 않으면 '불일치'입니다.
- **가까운 정도** — 숙소에서 출발해 걸리는 시간(편도) 기준 5단계: 숙소 안·도보 5분 / 차량 15분 이내 / 차량 30분 이내 / 30분 초과 / 없음.
  **'가까움' 조건은 숙소 안·도보 5분 · 차량 15분 이내까지** 부합으로 판정합니다.
- **국내·해외 구분** — 상품(또는 숙소·골프장)의 국가·권역으로 자동 구분합니다. 표의 '적용'이 해외인 항목(공항 이동·한식당·공항 픽업·관광 송영·장박 7박+)은 국내 상품 화면에 나오지 않고, 국내 상품은 장박 대신 **연박(2박 이상)**으로 판정합니다. 국내 상품의 '한식 접근'은 부합, '공항 60분 이내'·'관광 송영'은 '해당 없음(미확인)'으로 처리합니다.
- **입력한 값은 고객에게 근거로 보입니다** — 확인된 정보만 넣어 주세요.

## 2. 숙소·골프장 등록부 (한 번 등록 → 여러 상품에서 연결)
- 상품의 ① 숙박·객실 / ② 골프코스·라운드에서 **"등록부에서 선택"**으로 연결하거나 **"새로 등록"**합니다.
- 등록부 정보를 고치면 연결된 모든 상품에 반영됩니다(카드에 "상품 N개 연결" 표시).
- 예전에 상품에 직접 입력한 숙소·골프장 값이 있으면 **"등록부로 옮기고 연결"** 버튼이 보입니다. 옮기기 전에도 판정에는 그대로 쓰입니다.

## 4. 요금 항목마다 다른 경우 (예: 조식 / 조식+석식 / 전 식사)
- 한 상품에 요금 항목을 여러 개 두어 구성이 다르면, 위 상품별 정보에는 **공통값만** 두고 각 요금 항목의 **🤖 AI 추천 정보(이 항목만)**에 그 항목 값을 입력합니다. 비워 둔 칸은 상품 공통값을 그대로 씁니다.
- 요금 항목에서 따로 입력할 수 있는 항목: 포함 식사, 포함 식사 횟수, 상품 구성, 출발 가능 인원, 이 항목의 숙소(상품에 연결된 숙소 중 선택), 이 항목의 골프장(상품에 연결된 골프장 중 선택), 인원별 추가요금, 1인실 추가요금, 특가 기간, 현지 필수 지불금, 현지 추가 지불 없음.
- **판정** — 요금 항목마다 따로 판정해 ① 고객의 필수 조건(예산·일정·출발 시기)을 어기지 않고 ② 적합도가 가장 높은 항목을 고릅니다. 같으면 판매가가 낮은 항목. 판매가 비교도 그 항목의 판매가로 합니다.
- **고객 화면** — 추천 카드에 "🏷 추천 요금 항목: (항목 대표 문구)"가 표시되고, 상담 신청서의 세부 요청에도 함께 적힙니다. 대표 문구가 비어 있으면 '항목 01'처럼 표시되므로 대표 문구를 입력해 두는 것이 좋습니다.

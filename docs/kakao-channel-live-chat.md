# 카카오톡 채널 문의 알림 받기 + 홈페이지 실시간 상담으로 유도하기

> **먼저 알아둘 점**: 일반(무료) 카카오톡 채널의 1:1 채팅 메시지는 홈페이지 실시간 상담으로 **자동 전달되지 않습니다**(카카오가 문의 수신 웹훅을 제공하지 않음 — 상담톡은 딜러사 계약이 필요한 유료 상품이고, 쓰면 채널 관리자센터의 채팅 메뉴를 못 씁니다).
> 그래서 두 가지를 함께 합니다. ① **카카오 채널 문의 알림을 담당자 폰으로 즉시 받기**, ② **카나나 봇 안내에서 홈페이지 실시간 상담 링크로 고객을 유도하기**(홈페이지 상담은 이미 소리·바탕화면 알림이 있습니다).
> 아래 카카오 쪽 메뉴 이름은 화면 업데이트에 따라 조금 다를 수 있습니다. 찾기 어려우면 화면을 캡처해서 알려주세요.

## 1. 카카오톡 채널 문의 알림 받기 (무료)
1. 상담 담당자 **모두**가 폰에 **「카카오톡 채널 관리자」 앱**(안드로이드·아이폰 공통)을 설치하고 채널 관리자 계정으로 로그인합니다.
2. 채널 관리자센터(<https://center-pf.kakao.com>) → **관리 › 관리자(멤버) 관리**에서 담당자를 관리자로 추가합니다. 담당자마다 따로 계정이 있어야 알림이 각자 폰으로 옵니다. 한 명에게만 알림이 가면 그 사람이 자리를 비울 때 문의를 놓칩니다.
3. 앱 **설정 › 알림**에서 채팅(1:1 채팅) 알림을 켭니다. 폰 자체 설정(앱 알림 허용, 무음·방해금지 예외)도 확인하세요.
4. **상담 시간 안내 설정**: 관리자센터 **채팅 › 설정**에서 상담 가능 시간과 **부재중 자동 응답 메시지**를 넣어 둡니다(아래 4번 문구 참고).
5. 시험: 다른 카카오 계정으로 채널에 메시지를 보내 담당자 폰에 알림이 뜨는지 확인합니다.

> 담당자가 알림을 놓치지 않도록, 상담 시간에는 앱 알림음을 켜 두고 **응답 목표 시간**(예: 5분 이내 첫 답변)을 정해 두세요.

## 2. 홈페이지 실시간 상담 알림 (이미 있음)
관리자로 로그인해 두면 새 상담이 올 때 알림음, 왼쪽 아래 💬 버튼 깜박임과 빨간 숫자, **바탕화면(푸시) 알림**이 옵니다. 켜는 방법은 `docs/live-chat-setup.md`의 "2-1. 알림 받기"를 보세요. 카카오 알림과 별개이므로 담당자는 **카카오 채널 앱 알림 + 홈페이지 상담 알림**, 두 곳을 확인하게 됩니다.

### 이렇게 하면 좋은 이유와 한계
- 홈페이지 실시간 상담은 고객 이름·연락처·성별·출발지역이 구조화되어 저장되고, 상담 기록·메모·통계·엑셀 내보내기를 한곳에서 관리할 수 있습니다. 카카오 대화는 이 기록에 자동으로 들어오지 않으므로, 가능하면 상담을 홈페이지 쪽으로 모으는 것이 관리에 유리합니다.
- 다만 고객이 카카오톡 안에서 계속 대화하고 싶어 하는 경우가 많습니다. 링크를 **강요하는 문구보다 선택지**로 안내하세요(예: "카카오로 이어서 하셔도 되고, 홈페이지 상담도 가능합니다").
- 카카오 채널 대화는 카카오 관리자센터에서만 보이고, 홈페이지 상담 목록과는 연결되지 않습니다. 두 곳의 문의를 모두 확인하는 담당자를 정해 두세요.

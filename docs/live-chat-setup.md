# 실시간 상담(채팅) 설정과 사용법

홈페이지 왼쪽 아래의 **💬 실시간 상담** 버튼으로 방문자가 상담을 시작하고, 관리자 패널의 **💬 실시간 상담** 탭에서 상담원이 실시간으로 답변합니다.
별도 외부 서비스 없이 지금 쓰는 Supabase에 대화가 저장됩니다.

## 1. 한 번만 설정 (순서대로)

> ⚠️ **반드시 SQL(1-1)을 먼저 실행한 뒤에 코드를 병합(1-2)하세요.**
> SQL 없이 병합하면 방문자에게 상담 버튼은 보이지만 연결이 되지 않습니다.

**1-1. Supabase에 채팅 테이블 만들기**
1. <https://supabase.com/dashboard> → 프로젝트 `zjanojlayndtgmzohpyb` → 왼쪽 **SQL Editor** → **New query**
2. 저장소의 `docs/sql/2026-10-28_live_chat.sql` 내용을 **전부 복사해 붙여 넣고** **Run**
3. 맨 아래 결과에 `tgt_chat tables | 3` 이 나오면 성공입니다. (여러 번 실행해도 안전합니다)
   - `tgt_is_admin` 이 없다는 오류가 나오면 먼저 `docs/sql/2026-10-24_crm_core.sql`을 실행하세요.

**1-2. 코드 병합(배포)** — 이 기능이 담긴 PR을 `main`에 병합하면 1~3분 뒤 라이브에 반영됩니다.

## 2. 상담원(관리자) 사용법
1. `https://thegolftrend.co.kr/?admin` → 관리자 로그인
2. 로그인해 두면 **새 상담·새 메시지가 오면 알림음이 울리고**, 탭 이름 옆과 브라우저 탭 제목에 숫자가 표시됩니다.
3. 패널의 **💬 실시간 상담** 탭
   - **상담 대기 중** 체크: 켜 두면 고객 화면에 "상담원 온라인"이 표시됩니다. (이 관리자 화면이 열려 있는 동안만)
   - 왼쪽 목록에서 상담을 눌러 대화를 보고 아래 입력창에 답변합니다. (Enter 전송 · Shift+Enter 줄바꿈)
   - **상담 종료**: 고객 화면에 종료 안내가 나갑니다. 고객이 다시 글을 보내면 상담이 다시 열립니다.
   - **삭제**: 대화와 연락처를 완전히 지웁니다(되돌릴 수 없음). 보유 기간(상담 종료 후 1년)이 지난 상담은 이 버튼으로 정리하세요.
   - 📞 전화번호를 누르면 고객에게 바로 전화할 수 있습니다.
4. 상태 표시: **대기**(상담원 답변 전) · **상담중** · **종료**. 빨간 숫자는 안 읽은 고객 메시지 수입니다.

> 관리자 화면(브라우저 탭)이 꺼져 있으면 알림이 울리지 않고 고객 화면에는 "상담원 온라인"이 표시되지 않습니다.
> 운영시간에는 관리자 화면을 열어 두세요. 놓친 메시지는 다음에 열 때 목록에 모두 남아 있습니다.

## 3. 방문자 화면
- 첫 화면: 인사말 + **이름·연락처·개인정보 수집·이용 동의(필수)** 입력 → **상담 시작**
- 시작 후: 자동 안내 버튼(AI 골프여행 추천, 여행지·상품 보기, 견적·가격 문의, 취소·환불 규정, 상담 신청서, 전화, 카카오톡)과 메시지 입력창이 나옵니다. `+` 버튼은 같은 메뉴를 다시 엽니다.
- **자동 안내(챗봇)** 는 등록된 정보(연락처·약관 링크·사이트 메뉴)로만 안내하고, 가격·일정을 지어내지 않습니다. 견적은 상담원이 확인해 답변합니다.
- 운영시간 **평일 09:00–18:00(한국 시간)** 밖에는 "메시지를 남겨 주시면 운영시간에 답변드립니다"로 안내하고, 남긴 메시지는 저장됩니다.
- 같은 기기에서는 창을 닫았다 열어도, 새로고침해도 진행 중인 상담이 이어집니다. 상담원이 답하면 버튼에 빨간 숫자가 표시됩니다.
- 운영시간을 바꾸려면 `assets/live-chat.js` 맨 위 `HOURS`(요일·시작·종료)를 수정하세요.

## 4. 개인정보·보안
- 수집 항목: 이름, 연락처, 대화 내용 / 목적: 실시간 상담 응대 / 보유: 상담 종료 후 1년 — 개인정보처리방침에 "실시간 채팅 상담" 항목을 추가해 주세요(`docs/privacy-policy-checklist.md` 참고).
- 방문자는 테이블에 직접 접근할 수 없고, 상담을 시작할 때 발급된 **비밀 토큰**으로만 자기 대화를 읽고 씁니다. 다른 사람의 대화·연락처는 볼 수 없습니다.
- 도배 방지: 같은 연락처로 10분에 5건 초과 시작 불가, 한 상담에서 1분에 20건 초과 전송 불가.
- 상담원 화면은 `tgt_is_admin()`으로 허용된 관리자 계정만 사용할 수 있습니다.

## 5. 문제 해결
| 증상 | 확인 |
|---|---|
| 고객 화면에 "실시간 상담이 아직 준비되지 않았어요" | 1-1 SQL을 실행하지 않았거나 실패. SQL Editor에서 다시 실행 |
| 관리자 탭에 "데이터베이스가 아직 준비되지 않았어요" | 같은 원인 |
| 관리자 화면이 비어 있고 불러오기 실패 | 관리자 로그인 계정이 `tgt_admins`에 등록되어 있는지 확인(CRM 설정 문서 `docs/crm-setup.md`) |
| 고객 메시지가 안 보임 | 관리자 화면을 새로고침하고 **💬 실시간 상담** 탭을 다시 열기 |
| 알림음이 안 나옴 | 탭의 "새 메시지 알림음" 체크 확인, 브라우저에서 소리 허용(관리자 화면을 한 번 클릭한 뒤부터 재생 가능) |
| 기능을 완전히 끄고 싶음 | `docs/sql/2026-10-28_live_chat_rollback.sql` 실행(대화 기록이 모두 삭제됩니다) + 코드에서 `#tgtChatFab` 버튼 제거 |

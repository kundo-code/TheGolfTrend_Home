# 실시간 상담(채팅) 설정과 사용법

홈페이지 왼쪽 아래의 **💬 실시간 상담** 버튼으로 방문자가 상담을 시작하고, 상담원은 **같은 버튼(관리자 로그인 상태)** 또는 관리자 패널의 **💬 실시간 상담** 탭에서 실시간으로 답변합니다.
별도 외부 서비스 없이 지금 쓰는 Supabase에 대화가 저장됩니다.

## 1. 한 번만 설정 (순서대로)

> ⚠️ **SQL을 먼저 실행한 뒤에 코드를 병합(배포)하세요.**
> 2단계 SQL 전에 병합해도 상담·답변은 되지만, 성별·출발지역이 별도 칸이 아닌 첫 메시지로만 남고 메모·담당·통계·2중 비밀번호는 쓸 수 없습니다.

**1-1. Supabase에 채팅 테이블 만들기 (1단계 — 이미 했다면 건너뛰기)**
1. <https://supabase.com/dashboard> → 프로젝트 `zjanojlayndtgmzohpyb` → 왼쪽 **SQL Editor** → **New query**
2. 저장소의 `docs/sql/2026-10-28_live_chat.sql` 내용을 **전부 복사해 붙여 넣고** **Run**
3. 맨 아래 결과에 `tgt_chat tables | 3` 이 나오면 성공입니다. (여러 번 실행해도 안전합니다)
   - `tgt_is_admin` 이 없다는 오류가 나오면 먼저 `docs/sql/2026-10-24_crm_core.sql`을 실행하세요.

**1-2. 2단계 SQL (성별·출발지역·메모·여러 상담원·대기 시간·통계·2중 비밀번호)**
1. 같은 SQL Editor에서 **New query** → `docs/sql/2026-10-29_live_chat_v2.sql` 내용을 전부 붙여 넣고 **Run**
2. 맨 아래 결과가 `tgt_chat v2 columns | 8`, `tgt_admin_pin table | 1` 이면 성공입니다. (여러 번 실행해도 안전, 기존 상담·대화는 그대로)

**1-3. 코드 병합(배포)** — 이 기능이 담긴 PR을 `main`에 병합하면 1~3분 뒤 라이브에 반영됩니다.

## 2. 상담원(관리자) 사용법

### 2-1. 알림 받기
`https://thegolftrend.co.kr/?admin` → 관리자 로그인. 로그인해 두면 홈페이지 어느 화면에 있든
- **왼쪽 아래 💬 실시간 상담 버튼**이 남색(상담원용)으로 바뀌고, 답변을 기다리는 상담 수가 **빨간 숫자**로 표시되며 버튼이 깜박입니다.
- **알림음**(`assets/sounds/chat-notify.mp3`, 볼륨 70%)이 울리고, 패널 탭과 브라우저 탭 제목에도 숫자가 붙습니다.
- **🖥 바탕화면(푸시) 알림**을 켜면 다른 탭·프로그램을 보고 있어도 운영체제 알림("💬 새 상담 요청 · 홍*동 · 경기도 수원시")이 뜹니다. 알림을 누르면 그 상담이 바로 열립니다.
  - 처음 켤 때 브라우저가 "알림 허용"을 물으면 **허용**을 누르세요. 막혀 있으면 주소창 왼쪽 자물쇠 → 알림 → 허용.
  - 사이트가 브라우저 탭에 **열려 있는 동안**만 옵니다(브라우저를 완전히 닫으면 받을 수 없음). 아이폰은 사파리 정책상 홈 화면에 추가한 경우만 지원됩니다.
- 브라우저는 화면을 한 번도 누르지 않은 페이지의 소리를 막을 수 있습니다. 관리자 화면을 새로 연 뒤에는 **아무 곳이나 한 번 눌러** 주세요.

### 2-2. 왼쪽 아래 상담원 창에서 바로 응대
관리자 로그인 상태에서 **💬 실시간 상담** 버튼을 누르면 고객용 창 대신 **상담원 창**이 열립니다.
- 목록 → 상담을 누르면 대화가 열리고, 아래 입력창에 답변(Enter 전송 · Shift+Enter 줄바꿈)
- **패널에서 보기**: 관리자 패널의 실시간 상담 탭으로 이동(메모·CRM 기록·삭제는 패널에서)
- **고객 화면**: 고객이 보는 상담창을 미리 봅니다

### 2-3. 관리자 패널 → 💬 실시간 상담 탭
| 화면 | 내용 |
|---|---|
| 💬 상담 | 목록·대화·답변·상담 종료·삭제. **답변을 기다리는 상담이 오래 기다린 순서로 맨 위**에 오고 `⏱ N분째 대기`가 표시됩니다(5분 이상 주황, 15분 이상 빨강). 대화 위에서 **메모 저장**, **📝 CRM 상담 기록** |
| 👥 고객 정보 | 상담 고객의 이름·연락처(일부 가림)·성별·출발지역·상태·담당·**메모**. 기간·상태·성별·지역·검색으로 거르고 **📊 엑셀(.xlsx) 내보내기 / ⬇ CSV 내려받기**(2중 비밀번호 확인, "대화 내용 포함" 선택 가능) |
| 📈 통계 | 기간별 상담 수, 답변한 상담 비율, 첫 답변 시간(중앙값·평균·5분 내 비율), 종료율, 운영시간 외 접수 비율, 날짜별·시간대별 접수, 문의 주제, 상담원별 담당, 성별, 출발지역 |
| ⚙️ 설정 | 상담원 표시 이름, 알림, **2중 관리자 비밀번호 등록·변경·삭제** |

- **상태**: 대기(상담원 답변 전) · 상담중 · 종료. 빨간 숫자는 안 읽은 고객 메시지 수입니다.
- **상담 종료**: 고객 화면에 종료 안내가 나갑니다. 고객이 다시 글을 보내면 상담이 다시 열립니다.
- **삭제**: 대화와 연락처를 완전히 지웁니다(되돌릴 수 없음). 보유 기간(상담 종료 후 1년)이 지난 상담은 이 버튼으로 정리하세요.

### 2-4. 여러 상담원이 함께 응대할 때
- 상담원마다 관리자 계정(`tgt_admins`에 등록)으로 로그인하고, ⚙️ 설정에서 **상담원 표시 이름**(예: 김상담)을 저장하세요.
- 상담에 처음 답변한 상담원이 자동으로 **담당**이 됩니다. 목록에 `👤 내 담당` / `👤 김상담`으로 표시됩니다.
- 다른 상담원이 담당인 상담에 답변하면 "○○ 님이 응대 중인 상담입니다. 대신 답변하고 담당을 가져올까요?"를 묻습니다(중복 답변 방지). **내가 맡기 / 담당 가져오기 / 담당 해제** 버튼으로 직접 바꿀 수도 있습니다.
- 대화에는 어느 상담원이 답했는지(상담원 김상담 14:02) 남습니다. 고객 화면에는 "상담원"으로만 보입니다.
- 상담원 중 한 명이라도 "상담 대기 중"을 켜고 화면을 열어 두면 고객 화면에 "상담원 온라인"이 표시됩니다.

### 2-5. 채팅 → CRM 상담 기록
대화 위의 **📝 CRM 상담 기록**을 누르면 **상담·예약** 탭의 빠른 기록이 열리고 이름·연락처·성별·출발지역·메모·대화가 채워집니다(상담 경로: 실시간 채팅).
상품·고객 취향·상담 결과를 고르고 **저장**하면 그 채팅에 CRM 번호가 연결되고, 다음부터는 같은 버튼이 **후속 기록**으로 이어집니다.

## 3. 2중 관리자 비밀번호(숫자 4자리)
- **언제 묻나요**: 고객 정보 엑셀·CSV 내보내기, 관리자 패널 아래 **전체 초기화**, **상품 초기화**를 누를 때.
- **등록**: ⚙️ 설정에서 등록하거나, 처음 위 버튼을 누를 때 나오는 창에서 바로 등록합니다. 모든 관리자 계정이 같은 번호를 씁니다.
- **변경·삭제**: ⚙️ 설정에서 현재 번호를 입력하고 변경/삭제.
- **보안**: 번호 원문은 저장하지 않고 암호화(bcrypt)된 값만 Supabase에 저장합니다. 10분에 5번 틀리면 그 계정은 10분 동안 잠기고, 확인·변경 기록(누가·언제·무엇을·성공 여부)은 `tgt_admin_pin_log`에 남습니다.
- **잊어버렸을 때**: Supabase SQL Editor에서 `delete from public.tgt_admin_pin;` 실행 → 관리자 화면에서 새로 등록.
- 2단계 SQL을 실행하기 전에는 초기화 버튼에서 "비밀번호 없이 진행"을 고를 수 있고, 내보내기는 할 수 없습니다.

## 4. 상담 업무시간 · 상담 신청서 → 실시간 상담 바로 연결
- **업무시간 설정**: 관리자 패널 **💬 실시간 상담 → ⚙️ 설정 → 🕘 상담 업무시간**에서 요일·시작·종료 시각(한국 시간)을 고르고 **저장**. 관리자 로그인 상태에서 저장하면 모든 방문자 화면에 공유됩니다(기본값 평일 09:00–18:00).
  - 홈페이지의 "평일 09:00–18:00" 안내 문구(탑승권 오른쪽 · 아래 상담 문의 줄)와 고객 상담 창의 운영시간 안내가 이 값으로 바뀝니다.
- **업무시간 안**: 예약 문의(탑승권)에서 이름·연락처·**성별·출발지역**·동의를 입력하고 **상담 신청하기**를 누르면, 접수 완료와 함께 **왼쪽 아래 실시간 상담 창이 바로 열립니다**. 신청서에 입력한 정보가 그대로 쓰여 채팅 시작 화면을 다시 거치지 않고, 신청 내용(접수번호·여행지·일정 등)이 첫 메시지로 상담원에게 전달됩니다.
- **업무시간 밖**: 채팅은 열지 않고 접수 완료 화면에 "지금은 상담 업무시간(…)이 아니에요. 남겨 주신 내용은 다음 업무일 ○/○(요일) 09:00 이후에 담당 플래너가 확인한 뒤 상담을 진행해 드립니다."를 안내합니다. 고객이 직접 상담 창을 열어도 같은 안내가 나옵니다.

## 5. 방문자 화면
- 첫 화면: 인사말 + **이름·연락처·성별(남/여)·출발지역(시/도 → 시/군/구 선택)·개인정보 수집·이용 동의(필수)** → **상담 시작**
  - 출발지역은 시/도를 고르면 그 지역의 시/군/구만 고를 수 있습니다(세종특별자치시는 시/군/구 없음). 목록은 `index.html`의 `KR_REGIONS`(상담 신청서와 공용)에서 바꿀 수 있습니다.
- 시작 후: 자동 안내 버튼(AI 골프여행 추천, 여행지·상품 보기, 견적·가격 문의, 취소·환불 규정, 상담 신청서, 전화, 카카오톡)과 메시지 입력창. 상담원 답변 전에는 상단에 "답변 대기 N분째"가 표시됩니다.
- **자동 안내(챗봇)** 는 등록된 정보(연락처·약관 링크·사이트 메뉴)로만 안내하고, 가격·일정을 지어내지 않습니다.
- 상담 업무시간(4번에서 설정) 밖에는 "다음 업무일에 확인 후 상담을 진행해 드립니다"로 안내하고, 남긴 메시지는 저장됩니다.
- 같은 기기에서는 창을 닫았다 열어도, 새로고침해도 진행 중인 상담이 이어집니다. 상담원이 답하면 버튼에 빨간 숫자가 표시됩니다.

## 6. 개인정보·보안
- 수집 항목: 이름, 연락처, 성별, 출발지역(시/도·시/군/구), 대화 내용 / 목적: 실시간 상담 응대 / 보유: 상담 종료 후 1년 — 개인정보처리방침의 "실시간 채팅 상담" 항목에 성별·출발지역을 추가해 주세요(`docs/privacy-policy-checklist.md`).
- **화면 마스킹**: 상담 목록·상담원 창·고객 정보 표에서 이름은 2글자면 두 번째 글자(홍*), 3글자면 가운데 글자(홍*동), 4글자 이상은 처음·끝 글자만 남기고(남**수), 연락처는 가운데 번호를 가립니다(010-****-5678). 가리지 않은 정보는 2중 비밀번호를 확인한 내보내기 파일에만 담깁니다.
- 내려받은 파일은 상담 목적에만 쓰고, 사용 후 삭제하거나 암호를 걸어 보관하세요.
- 방문자는 테이블에 직접 접근할 수 없고, 상담을 시작할 때 발급된 **비밀 토큰**으로만 자기 대화를 읽고 씁니다.
- 도배 방지: 같은 연락처로 10분에 5건 초과 시작 불가, 한 상담에서 1분에 20건 초과 전송 불가.
- 상담원 화면은 `tgt_is_admin()`으로 허용된 관리자 계정만 사용할 수 있습니다.

## 7. 문제 해결
| 증상 | 확인 |
|---|---|
| 고객 화면에 "실시간 상담이 아직 준비되지 않았어요" | 1-1 SQL을 실행하지 않았거나 실패. SQL Editor에서 다시 실행 |
| 관리자 탭에 "데이터베이스가 아직 준비되지 않았어요" | 같은 원인 |
| 관리자 탭 위에 "2단계 SQL을 실행해 주세요" 안내 | 1-2 SQL 실행 |
| 관리자 화면이 비어 있고 불러오기 실패 | 관리자 로그인 계정이 `tgt_admins`에 등록되어 있는지 확인(`docs/crm-setup.md`) |
| 알림음이 안 나옴 | "🔔 알림음" 체크 확인, 관리자 화면을 한 번 클릭, PC·휴대폰 볼륨·무음 모드 확인 |
| 바탕화면 알림이 안 옴 | "🖥 바탕화면(푸시) 알림" 체크, 브라우저 알림 허용, 윈도우/맥의 방해 금지(집중) 모드 확인. 지금 보고 있는 탭이면 소리·배지만 표시됩니다 |
| 2중 비밀번호를 잊음 | SQL Editor에서 `delete from public.tgt_admin_pin;` 실행 후 새로 등록 |
| "여러 번 틀려 10분 동안 잠겼습니다" | 10분 뒤 다시 시도 |
| 기능을 완전히 끄고 싶음 | `docs/sql/2026-10-29_live_chat_v2_rollback.sql` → `docs/sql/2026-10-28_live_chat_rollback.sql` 순서로 실행(대화 기록이 모두 삭제됩니다) + 코드에서 `#tgtChatFab` 버튼 제거 |

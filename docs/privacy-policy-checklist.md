## 1. 수집 항목 · 방법
| 구분 | 항목 | 수집 방법 | 근거 |
|---|---|---|---|
| 필수 | 이름, 연락처 | 상담 신청 폼(탑승권) 직접 입력 | `index.html` `#bookingForm` |
| 선택 | 희망 여행지, 출발 시기(월), 인원, 체류 기간, 숙박 타입, 여행 스타일, 문의 내용, 연락 방법·시간, 전하고 싶은 말 | 폼에서 선택·입력 | 〃 |
| 자동(익명) | 방문 세션 ID(탭 단위), 유입 도메인, 기기 종류, 광고 태그(utm), 페이지·상품 조회·클릭, 상담 신청 시작·제출 여부 | 접속 시 자동 기록(쿠키 아님, `sessionStorage`) · 이름·연락처·IP는 기록하지 않음 | `tgtTrack` / `tgt_site_events` |
| 생성 | 접수번호, 개인정보 동의 일시·문구 버전, 선택 동의 여부 | 접수 시 자동 생성 | `kundo_leads` |
| 관리 | 상담 기록·메모, 예약 데이터(예약번호·고객명·연락처 등) | 상담원이 직접 기록 / 예약 CSV 가져오기 | 관리자 패널 상담·예약 탭 |

## 2. 처리방침에 있어야 할 항목
- [ ] 위 **수집 항목**(필수/선택 구분) 과 **자동 수집 항목**(세션 ID·유입 도메인·기기·조회 기록)
- [ ] **이용 목적**: 상담·견적 안내, 문의 응대, (선택 동의 시) 소식·혜택 안내 — 상담 폼 동의문과 같은 문구
- [ ] **보유·이용 기간**: 폼 동의문은 현재 "상담 종료 후 1년(관계 법령에 따라 보존이 필요한 경우 해당 기간)" — **처리방침과 반드시 같은 기간**으로 통일(`index.html`의 `LEAD_CONSENT.retention`)
- [ ] **선택 동의(소식·혜택 안내)**: 수집 항목(이름·연락처), 목적, 보유 기간(철회 시까지), **철회 방법**
- [ ] **처리 위탁 / 저장 위치**: Supabase(DB·로그인·파일 저장) — 서버 위치가 국외이면 **국외 이전** 고지(이전 국가·시기·방법·업체·보유기간)
- [ ] **제3자 제공**: 현재 코드상 제3자 제공 없음(있다면 기재)
- [ ] **외부 서비스로 전달되는 정보**: 호스팅(GitHub Pages), 폰트·스타일 CDN(Google Fonts, jsDelivr)에 방문 시 IP 등이 전달될 수 있음
- [ ] **카카오톡 채널·네이버 밴드**로 이동 시 해당 서비스의 약관·정책이 적용된다는 안내
- [ ] **파기 절차·방법**: 파기 시점, DB 삭제 방식, **내려받은 CSV·백업 파일**의 파기
- [ ] **정보주체 권리**: 열람·정정·삭제·처리정지 요구와 동의 철회 방법·연락처(전화 010-9405-6842 / thegolftrend@gmail.com)
- [ ] **개인정보 보호책임자**: 맹군도 (푸터 표기와 성명·연락처 일치)
- [ ] **안전성 확보 조치**: 관리자만 열람(권한 분리), 접속 기록 보관, 전송 구간 암호화(HTTPS) 등 실제 수행하는 것만
- [ ] **아동(만 14세 미만)** 개인정보를 수집하지 않는다는 문구
- [ ] **시행일·개정 이력** (동의 문구 버전 `LEAD_CONSENT.version` 과 함께 관리)

## 3. 점검 방법
1. 처리방침 본문을 위 표와 나란히 놓고 빠진 항목에 체크
2. 처리방침을 고치면 `LEAD_CONSENT`(index.html) 의 보유 기간 등 동의 문구도 맞추고 `version`을 올리기 → 이후 접수부터 새 버전이 동의 기록에 남음
